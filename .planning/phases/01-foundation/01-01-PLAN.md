# Plan 01-01: Scaffold progetto Android

## Objective
Creare la struttura base del progetto Android con Kotlin, Jetpack Compose, Hilt e Room già configurati nel `build.gradle`. L'app deve compilare ed avviarsi con una `MainActivity` vuota.

## Context
- @.planning/BRIEF.md
- Min SDK 26, Target SDK 34
- Kotlin 1.9+, Compose BOM 2024.x, Hilt 2.50+, Room 2.6+

## Tasks

### Task 1: Crea struttura progetto Android
**Type:** create
**Action:**
Crea la struttura di directory standard Android:
```
app/
  src/main/
    AndroidManifest.xml
    java/com/example/player/
      MainActivity.kt
      PlayerApplication.kt
    res/
      values/strings.xml
      values/themes.xml
  build.gradle.kts  (app module)
build.gradle.kts    (root)
settings.gradle.kts
gradle/libs.versions.toml
```

**Manifest** — `AndroidManifest.xml`:
- Application name: `.PlayerApplication`
- Theme: `@style/Theme.Player`
- Permessi: `READ_MEDIA_AUDIO` (API 33+) e `READ_EXTERNAL_STORAGE` (API < 33)
- `<activity android:name=".MainActivity" android:exported="true">` con intent-filter MAIN/LAUNCHER

**`PlayerApplication.kt`**:
```kotlin
package com.example.player

import android.app.Application
import dagger.hilt.android.HiltAndroidApp

@HiltAndroidApp
class PlayerApplication : Application()
```

**`MainActivity.kt`**:
```kotlin
package com.example.player

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.compose.material3.Text
import dagger.hilt.android.AndroidEntryPoint

@AndroidEntryPoint
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            Text("Player")
        }
    }
}
```

**`res/values/strings.xml`**:
```xml
<resources>
    <string name="app_name">Player</string>
</resources>
```

**`res/values/themes.xml`**:
```xml
<resources>
    <style name="Theme.Player" parent="android:Theme.Material.Light.NoActionBar" />
</resources>
```

**Verify:** Tutti i file esistono. Il progetto può essere importato in Android Studio.

**Done:** ✅ quando tutti i file sono stati creati correttamente.
