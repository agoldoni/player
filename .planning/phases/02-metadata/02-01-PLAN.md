# Plan 02-01: File Picker + Permessi Storage

## Objective
Implementare il meccanismo per selezionare file MP3 dal dispositivo usando `ActivityResultContracts` e gestire i permessi di storage in modo compatibile con API 26-34.

## Context
- @.planning/BRIEF.md
- Min SDK 26 — permessi runtime `READ_EXTERNAL_STORAGE` (API < 33) / `READ_MEDIA_AUDIO` (API 33+)
- Il file picker deve essere invocabile da un FAB nella schermata principale

## Tasks

### Task 1: `PermissionHandler`
**Type:** create
**File:** `app/src/main/java/com/example/player/util/PermissionHandler.kt`

```kotlin
package com.example.player.util

import android.Manifest
import android.os.Build

object PermissionHandler {
    val STORAGE_PERMISSION: String
        get() = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
            Manifest.permission.READ_MEDIA_AUDIO
        } else {
            Manifest.permission.READ_EXTERNAL_STORAGE
        }
}
```

**Done:** Oggetto utility che espone il permesso corretto per versione API.

### Task 2: `MusicFilePicker` Composable
**Type:** create
**File:** `app/src/main/java/com/example/player/util/MusicFilePicker.kt`

```kotlin
package com.example.player.util

import android.content.Context
import android.net.Uri
import androidx.activity.compose.rememberLauncherForActivityResult
import androidx.activity.result.contract.ActivityResultContracts
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember

/**
 * Ritorna una lambda che apre il file picker per selezionare più file audio.
 * Chiama [onFilesPicked] con la lista di URI selezionati.
 */
@Composable
fun rememberMusicFilePicker(
    onFilesPicked: (List<Uri>) -> Unit
): () -> Unit {
    val launcher = rememberLauncherForActivityResult(
        contract = ActivityResultContracts.GetMultipleContents()
    ) { uris ->
        if (uris.isNotEmpty()) onFilesPicked(uris)
    }
    return remember { { launcher.launch("audio/mpeg") } }
}
```

**Done:** Composable che lancia `GetMultipleContents` con MIME type `audio/mpeg`.
